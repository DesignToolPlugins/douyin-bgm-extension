# 抖音 BGM 采集器（Chrome 插件版）

> 🔰 **第一次用 / 不熟电脑的同事** → 请直接看 **[`使用说明-新手必读.md`](./使用说明-新手必读.md)**，一步步图文说明
>
> 下面是快速版，适合装过 Chrome 插件的人。

从抖音创作服务平台「创作灵感 → 热门音乐」榜单一键批量下载 MP3。

**优势**：
- ✅ 不用装 Python
- ✅ 不用装 kimi-webbridge
- ✅ 不用命令行
- ✅ 直接在 Chrome 右上角点图标就出活

---

## 📦 安装（一次性）

### 方式一：本地加载（推荐 —— 免开发者账号）
1. Chrome 打开 `chrome://extensions/`
2. 右上角打开「**开发者模式**」（开关）
3. 左上角「**加载已解压的扩展程序**」
4. 选择本文件夹 `C:\Tools\douyin-bgm-extension\`（或 zip 解压后的目录）
5. 右上角看到「抖音BGM采集器」图标 = 装好

### 方式二：分发给同事
- 把整个文件夹压缩成 zip 发微信 / 网盘
- 同事解压后按方式一装

---

## 🔑 登录（一次性）

Chrome 打开 <https://creator.douyin.com>，扫码登录一次。

**cookie 长期有效**，之后正常使用几周不用重登。**登录状态过期后**，插件会自动打开登录页提示重登。

---

## 🎯 用法

1. 点右上角插件图标
2. 选**时间窗**（24 小时 / 7 天 / 30 天）
3. 选**数量**（前 10 / 20 / 30 首）
4. 点「开始下载」
5. 等进度条走完（约 30 秒~1 分钟）
6. 去 `Downloads/douyin-bgm/YYYY-MM-DD_HHMM/` 找 MP3

**边下边看进度**：插件图标右下角有个小 badge 显示 `当前/总数`，下完变绿色 ✓。
**关闭 popup 也没事**：下载在后台继续，完成后 Chrome 会弹通知。

## 🩹 常见问题

- **点开始没反应 / 提示未登录** → 抖音 cookie 过期，插件会自动打开登录页，扫码后回来重试
- **提示接口报错** → 大概率也是登录问题，同上
- **下载完成但文件夹里少几首** → 少数音乐 CDN 偶发 403，看 popup 里「失败 X 首」，重试一次一般能补齐
- **想装 icon（工具栏上美观点）** → 目前用 Chrome 默认拼图图标，`manifest.json` 里 `action` 段加 `default_icon` 就能替换
- **换 user_id**：`background.js` 顶部 `USER_ID` 是硬编码值；如果所有请求都失败，去 Chrome DevTools → Network 找 `billboard/` 请求，把 URL 里 `user_id=` 后面的数字换进去
